# Validation scope

The Windows application assists an analyst with inspecting plate photographs and documenting candidate colony counts. It keeps original images, automatic detections and analyst edits separate.

The included synthetic practice image tests plate proposals, marker placement and the worked concentration examples. The synthetic workbook fixtures test mapping, calculations and preservation of spreadsheet source values. These fixtures do not measure accuracy on laboratory plates.

Performance can vary with image scale, focus, agar, reflections, rim effects, handwriting and touching or spreading growth. Review candidates against the original image. Review the selected method, dilution, plated volume, counting range and qualifiers before reporting. The ISO 7218:2024 calculation option is blocked pending controlled method verification. The FDA BAM numeric route excludes TNTC maximum-likelihood calculations.

Independent validation should use representative original laboratory images, documented counts from qualified reviewers, and a predefined acceptance criterion for each intended method and imaging setup. Keep those data separate from the public source tree. Clean-machine installation testing and independent laboratory validation remain pending for this pre-release.
