# FoodMicro Count 1.0.0 RC 1

This is the initial Windows x64 pre-release. The application displays Version 1.0 and identifies internally as 1.0.0. The candidate tag is `v1.0.0-rc.1`.

- Standalone per-user Setup includes the runtime, installation notices, illustrated Beginner Guide, synthetic practice image, licence and source archive.
- Plate analysis, review, local records and export work offline. The optional AI Assist path uses a separate explicit crop preview and approval.
- This public build uses a generic empty laboratory field for new projects. It includes a versioned synthetic Excel template and retains existing saved laboratory names when opening user records.
- The package provides software for evaluation. Clean-machine testing and independent laboratory validation are pending. Automatic detection and reporting require analyst review.

## Downloads

- `FoodMicroCount-1.0.0-Windows-x64-Setup.exe` is the unsigned installer.
- `FoodMicroCount-1.0.0-Source.zip` contains the full application source and build scripts from the release commit.
- `FoodMicroCount-1.0-Beginners-Guide.pdf` has the illustrated workflow and synthetic exercises.
- `SHA256SUMS.txt` identifies the three downloads and build provenance manifest.
- `BUILD_PROVENANCE.json` records the source commit and the hashes of the source archive and frozen executable.
