INSTALLATION
This per-user setup includes the runtime and works without a separate Python installation. It is unsigned. Check the download source and its SHA-256 checksum before running Setup.

UPGRADING
Use Backup in the existing app before upgrading. Sessions, original images and presets are stored separately in %LOCALAPPDATA%\FoodMicroCount. If you use a custom --data-dir, continue to point the app to that folder. Removing the program retains the separate records folder.

COUNTING AND REVIEW
Detection suggests candidate colonies. Check the plate boundary, lighting, overlapping growth, marker placement and method before using a result. The included plate image is synthetic practice data. Laboratory use requires verification with representative plates and the intended method.

OFFLINE USE AND OPTIONAL AI
Image counting, saving and export work offline. Optional AI Assist sends selected crops only when you approve their preview. Use it only for images you are permitted to share.

AFTER SETUP
Open FoodMicro Count from Start. The Start menu also includes the illustrated Beginner's Guide. The installation includes the GPL licence, the applicable LGPLv3 terms for Qt and Qt for Python, third-party notices, and corresponding application source.
